# kybur-legal

The three policy pages Meta requires before a developer app can be switched to Live:
privacy, terms and data deletion. Plain static HTML, Kybur black and violet.

- Live: https://patrickdxyofficial.github.io/kybur-legal/ (GitHub Pages, branch `main`, push = live)
- Used by: the Meta developer app TQW Social Backend (Settings, Basic)
- `assets/app-icon-1024.png` is the app icon uploaded to that app
- Brand-neutral on purpose: no account names, no TQW or BlvckOS wording
- Contact address on the pages: the BlvckOS support inbox, because a person reads it

When `legal.kybur.ai` gets its DNS record, add it as the custom domain in the repo's Pages
settings and swap the three links in the Meta app. Meta allows changing them at any time.
